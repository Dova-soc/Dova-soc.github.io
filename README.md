# 芥子 · 宿舍桌面数字化底座

一间宿舍，一张桌子，一套可以走进去看的模型。

**打开：** https://dova-soc.github.io/

手机扫码即可，无需安装。

---

## 这是什么

把宿舍家具量成三维模型，学生可以在浏览器里：

- 选园区 → 选楼栋（凌云 1–3 / 笃行 1–2 / 芙蓉 1–5，共 10 栋）
- 点进单张床位，看结构、看尺寸
- 换挂板、台灯、增高架、桌垫、显示器，摆好了再下单

三个园区是同一批采购家具，所以**一套模型十栋楼通用**。

## 技术

- 单 HTML 文件，零外部依赖，离线可用
- 自研深度缓冲光栅器，2 倍超采样（手机自动降档）
- Web Audio 实时合成音效，不打包音频
- 二维码用纯 Python 手写生成（无第三方库）
