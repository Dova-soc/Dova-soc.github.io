怎么在手机上看 · 完全离线
================================================================

先说结论
----------------------------------------------------------------
这个模型本身就是**离线文件**，不需要网络、不需要服务器、不需要
任何一台电脑在跑。

你只要把文件放进手机，用浏览器打开就行。


一、把文件放到手机里
----------------------------------------------------------------
任选一种：

  微信     发给「文件传输助手」→ 手机上点开 → 右上角「···」
           → 用其他应用打开 → 浏览器 / Chrome

  数据线   手机插电脑 → 把 jiezi.html 拷到手机的「下载」文件夹

  QQ/邮件  同样，发给自己，手机上另存


二、怎么打开
----------------------------------------------------------------
安卓
  1. 用「文件管理」找到 jiezi.html
  2. 长按 → 打开方式 → Chrome / 浏览器

  或者打开 Chrome，地址栏输入：
  file:///sdcard/Download/jiezi.html

iPhone
  1. 微信里点开文件 → 右上角「···」→「用其他应用打开」
  2. 选「存储到"文件"」
  3. 打开「文件」App → 找到 jiezi.html → 点它
     如果只是预览、转不动，改用下面的办法：
     下载一个免费的「Documents by Readdle」App，
     用它打开这个 html，里面是一个完整的浏览器。


三、手机上怎么操作
----------------------------------------------------------------
  单指拖动        旋转
  双指捏合        缩放
  点卡片          进园区
  点床位          进单床位
  左侧面板        换配件、套方案（手机上会从底部弹出）
  右下角 ⛶        清屏，只看模型


四、为什么不用二维码了
----------------------------------------------------------------
二维码里装的只是一个**网址**，网址要有人应答才能打开。

答辩现场没电脑、没网络，就没有人应答，二维码点了也是白屏。

所以正确的做法不是扫码，是**把文件本身放进手机**——
878 KB 的一个文件，发过去、点开就能转，全程不需要网络。

页面里没有任何外部请求（图片、字体、CDN 全都没有，已经逐项检查过）：
  http:// 出现 0 次
  <script src> 出现 0 次
  <link> 出现 0 次
  fetch / XMLHttpRequest 出现 0 次


五、万一手机打不开
----------------------------------------------------------------
不同手机的系统策略不一样，个别机型会限制本地 html。

备选方案（按可靠程度排）：

  1. 用教室的电脑。这个文件双击就能跑，不用装任何东西。
     带个 U 盘，或者提前发到自己的微信里，用教室电脑登录微信下载。

  2. 静态图。01 / 02 文件夹里每个角度都有 PNG，
     放到手机相册里翻着讲，一样能讲清楚。

  3. 让我导一个视频（模型转一圈 + 三套方案切换），
     存在手机里直接播，任何手机都能放。


六、建议
----------------------------------------------------------------
答辩前**一定先在自己手机上试一次**，用你当天要用的那台手机、
那个浏览器。试通了再上场。

如果试不通，告诉我机型，我换方案。
