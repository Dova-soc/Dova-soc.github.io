手机扫码查看 · 使用说明
================================================================

一、怎么用
----------------------------------------------------------------
双击  手机扫码查看.bat

会弹出一个黑窗口 + 一个浏览器页面（那个页面上的二维码放得很大）。

手机连**同一个 Wi-Fi**，用相机或微信扫那个二维码，就能在手机上打开
模型，可以转、可以缩放、可以点进床位换配件。

关掉黑窗口 = 服务停止。


二、为什么是这种方式
----------------------------------------------------------------
页面是一个 876 KB 的本地 HTML，手机没法直接打开电脑上的文件。
所以这里起了一个只对局域网开放的小服务，手机通过 Wi-Fi 访问这台电脑。

  不上传、不联网、不注册、不花钱。
  手机和电脑在同一个路由器（或同一个手机热点）下就行。


三、二维码里是什么
----------------------------------------------------------------
二维码内容就是这个地址：

  http://<这台电脑的局域网 IP>:8000/dorm.html

IP 每次开机会变，所以每次运行时都会**重新生成二维码**，不用手动改。


四、打不开怎么办
----------------------------------------------------------------
1. 手机和电脑是不是同一个 Wi-Fi？
   电脑连的是「以太网」、手机连的是 Wi-Fi，只要在同一个路由器下就行。

2. Windows 防火墙拦了
   第一次运行会弹「是否允许 Python 访问网络」，要选**允许**（专用网络）。
   已经点过「取消」的话，去「Windows 安全中心 → 防火墙和网络保护 →
   允许应用通过防火墙」里把 Python 勾上。

3. 校园网 / 公寓网的隔离
   很多学校的 Wi-Fi 开了「客户端隔离」，同一个 Wi-Fi 下的设备互相访问不了。
   这种情况下用**手机开热点**，电脑连手机热点，再运行一次就是新地址。

4. 还是不行
   直接在手机浏览器里输入黑窗口里显示的地址，效果一样。


五、手机上能做什么
----------------------------------------------------------------
  单指拖动          旋转
  双指捏合          缩放
  点床位            进入
  左侧面板          换配件、套方案
  右下角 ⛶          清屏欣赏
  Esc 无效，点 ⛶ 退出清屏

手机性能比电脑弱，页面会自动降分辨率保证跟手，静止时再补一帧高清。
第一次打开可能要等两三秒（要下 876 KB）。


六、文件说明
----------------------------------------------------------------
  手机扫码查看.bat     双击这个
  serve.py            服务本体（找 IP、开服务、生成二维码）
  qr.py               二维码生成器（纯 Python 写的，不依赖任何库）
  _扫码.html           运行时自动生成的说明页（二维码放得很大）
  public\              对外提供的文件
      dorm.html        页面的副本（每次运行自动从 03_交互展示 复制）
      qr.png           二维码

注意：黑窗口里的提示是英文的——因为中文在命令行里容易乱码，
中文说明都放在浏览器弹出的那个页面里。


七、改了模型之后
----------------------------------------------------------------
重新运行一次就行——它会重新复制最新的页面、重新生成二维码。

如果只是想更新页面，也可以手动把
  03_交互展示\宿舍交互展示.html
复制到
  手机查看\public\dorm.html
覆盖，然后刷新手机页面。
