这一版包含什么
----------------------------------------------------------------
交互流程（四级）
    选园区（凌云 / 笃行）
      → 选楼栋（凌云 1–3 / 笃行 1–2）
          → 宿舍总览（四个床位）
              → 单床位 + 自定义

转场
    园区 → 楼栋      卡片淡出，楼栋卡片错开 90ms 依次入场
    楼栋 → 宿舍      方盒子展开：画面切四片朝四边翻开，露出 3D
    宿舍 → 床位      相机飞行 950ms
    配件安装         几何体从中心弹出（0.2 → 1.12 → 1，260ms 回弹）

可自定义的 5 类
    左侧竖面      洞洞板 / 毛毡板 × 长 60 / 80（宽固定 30）
    台灯          书架隔板下 / 床板下（可都装）
    桌面          增高架 × 宽 60/76 × 高 6/10/14
    右侧竖面      手柄架 / 耳机架
    门和抽屉      4 扇门单独开关 + 抽屉可拉出

声音
    Web Audio 实时合成，不打包音频文件
    按钮 = 玻璃"叮"（2700Hz 三谐波 + 高频噪声瞬态）
    进入 = 低一档的"咚"（1650Hz）
    右下角 🔊 可一键静音

技术
    单 HTML 文件，零外部依赖，离线可用
    自研深度缓冲光栅器（每像素最近表面），2 倍超采样抗锯齿
    拖动时降分辨率保帧率，松手后补一帧高清
    配件照明按面法线 + 线段遮挡计算，灯不会照到背面或透过层板

如何重新生成
----------------------------------------------------------------
源码在 _源码\ 里，需要和工程目录配合使用：
    build_room3d.py   几何（DIMS 参数表在最上面）
    build_game.py     把几何 + 交互界面打包成一个 HTML
    render_pro.py     静态渲染器（导出预览图用）

正式工程目录：
    ..\..\宿舍桌面3D建模与尺寸记录\06_精细版3D\

把 _源码\ 里的三个文件覆盖回工程目录，运行 build_game.py 即可复现这一版。
