公网二维码 · 一次上传，永久可用
================================================================

地址：https://dova-soc.github.io/
二维码：最终模型\手机查看\二维码_公网.png

这个地址在公网上，任何人任何地方打开手机扫一下就能用，
不需要连你的热点，不需要你在场，也不需要电脑开着。


一、现在只差一步：把文件传上去
----------------------------------------------------------------
（我已经把仓库建好、Pages 也通了，现在就差那个页面文件）

  1. 浏览器打开
     https://github.com/Dova-soc/Dova-soc.github.io

  2. 右上角「Add file」→「Upload files」

  3. 把下面这个文件拖进去
     最终模型\上传到GitHub\index.html
     （它已经改好名字了，800 多 KB，拖进去要等几秒）

  4. 页面拉到下面，点绿色的「Commit changes」

  5. 等 1 分钟，访问 https://dova-soc.github.io/
     能看到模型就成了

之后这张二维码永远有效。


二、为什么这次能固定
----------------------------------------------------------------
前面几版的问题：

  局域网热点版   二维码固定，但看的人必须连你的热点，而且你要带电脑
  本地文件版     完全离线，但只能自己一个人看，没法"大家扫"

这一版把页面放在 GitHub 上（免费、永久、不需要你开任何东西）：

  谁都能扫 · 不用连热点 · 不用带电脑 · 不用你在线


三、答辩怎么用
----------------------------------------------------------------
1. 把 二维码_公网.png 放进 PPT，最好放一整页，够大
2. 现场说一句：「这个码不用注册，扫了就能转」
3. 大家扫，各自在手机上转、点床位、套方案

一次几十个人同时访问也没问题——GitHub 的服务器扛得住，
不是你的电脑在扛。


四、提前检查清单
----------------------------------------------------------------
□ 上传完成，https://dova-soc.github.io/ 能看到模型
□ 用你自己的手机流量（关掉 Wi-Fi）扫一次，确认不是只有校园网能开
□ 用别人的手机再扫一次
□ PPT 里那张二维码打印出来或投出来够不够大、扫不扫得动

第 2 条最重要：**关掉 Wi-Fi 用流量扫**，能打开才是真的公网可用。


五、可能的问题
----------------------------------------------------------------
1. 打开是占位页（写着"页面还没有上传"）
   → 文件没传成功，回到第一步重传

2. 打开很慢 / 打不开
   → GitHub 在国内偶尔不稳定。备选：
     · 手机用流量（不要连校园网，校园网对 github 可能有限速）
     · 现场用你的热点版兜底

3. 想改内容
   → 重新上传一次 index.html 覆盖即可，二维码不用换


六、以后不用了怎么删
----------------------------------------------------------------
GitHub 仓库设置里 Delete this repository 即可，
删掉后这个地址和二维码就失效了。
